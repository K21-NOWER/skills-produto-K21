# Produto K21

14 skills de gestão de produto em português do Brasil, feitas pela K21 e pela Nower para quem trabalha com produto, baseadas na metodologia da K21: **user-story**, **visao-do-produto**, **priorizacao**, **hipoteses**, **metricas-de-produto**, **udd-fatiamento**, **okr**, **saude-do-backlog**, **previsibilidade**, **papel-de-produto**, **discovery-com-clientes**, **estrategia-e-roadmap**, **apresentacao-de-produto** e **riscos-e-vieses**.

## Como usar

Depois de instalar, descreva a tarefa e o Claude usa a skill certa. Alguns pedidos de exemplo:

- "Avalie esta user story e dê uma nota."
- "Crie a visão do produto a partir desta ideia."
- "Priorize estes itens com o método mais adequado."
- "Avalie esta hipótese, sugira um experimento e escreva a user story."
- "Escreva meus OKRs do trimestre e diga o que está fraco."
- "Tenho 30 itens e 8 semanas de histórico. Quando fica pronto?"

Cada skill explica o raciocínio e mostra de onde veio cada nota, para você aprender enquanto usa.

## Dados

As skills não enviam dados para nenhum serviço externo, não pedem login e não usam conectores. Tudo o que você escreve fica na conversa com o Claude. As skills de priorização, saúde do backlog e previsibilidade incluem pequenos scripts em Python que apenas fazem contas com os números que você informa, localmente e sem acesso à internet.

Repositório completo, exemplos e instruções de instalação: https://github.com/K21-NOWER/skills-produto-K21
