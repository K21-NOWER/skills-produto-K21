# Produto K21

Quatro skills de gestão de produto em português do Brasil, feitas pela K21 e pela Nower para quem trabalha com produto: **user-story**, **visao-do-produto**, **priorizacao** e **hipoteses**.

## Como usar

Depois de instalar, descreva a tarefa e o Claude usa a skill certa. Alguns pedidos de exemplo:

- "Avalie esta user story e dê uma nota."
- "Crie a visão do produto a partir desta ideia."
- "Priorize estes itens com o método mais adequado."
- "Avalie esta hipótese, sugira um experimento e escreva a user story."

Cada skill explica o raciocínio e mostra de onde veio cada nota, para você aprender enquanto usa.

## Dados

As skills não enviam dados para nenhum serviço externo, não pedem login e não usam conectores. Tudo o que você escreve fica na conversa com o Claude. A skill de priorização inclui um pequeno script em Python que apenas faz contas com os números que você informa, localmente e sem acesso à internet.

Repositório completo, exemplos e instruções de instalação: https://github.com/K21-NOWER/skills-produto-K21
