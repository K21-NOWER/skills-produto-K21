# Código de conduta

Este é um espaço para aprender e melhorar produto juntos. Para isso funcionar:

- Trate as pessoas com respeito e boa-fé, inclusive quando discordar.
- Critique o texto, a nota ou a ideia, nunca a pessoa.
- Assédio, discriminação, ataques pessoais e a divulgação de dados de terceiros não têm espaço aqui.
- Não publique dados sigilosos de clientes ou empresas nas issues. Anonimize os exemplos.

Quem mantém o repositório pode editar ou remover comentários, issues e contribuições que fujam disso, e bloquear quem insistir. Para denunciar algo, abra uma issue ou fale com a K21 pelo [site](https://br.k21.global).
